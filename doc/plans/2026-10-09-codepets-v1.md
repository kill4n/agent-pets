# CodePets v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build CodePets, a Tauri desktop pet that shows one draggable transparent sprite window per Claude Code session, animated by the session's state.

**Architecture:** A Rust core (Tauri 2) collects events from an HTTP hooks server and a `claude agents --json --all` poller, normalizes them to `AgentEvent`, feeds a pure state machine held in a `Store`, and a window manager mirrors the store into one transparent WebView per agent. The UI (Vite + TypeScript) renders spritesheet animations from a validated pack manifest and reports drag positions back.

**Tech Stack:** Rust 1.93, Tauri 2 (stable, `tray-icon` feature), axum 0.8, tokio 1, serde/serde_json, directories 6, hostname 0.4, rand 0.9, png 0.17; Node 26, Vite 6, TypeScript 5, `@tauri-apps/api` 2, `@tauri-apps/plugin-autostart` 2, `pngjs` (dev, to generate the default pack).

**Spec:** `doc/specs/2026-10-07-codepets-design.md`

## Global Constraints

- Tauri **2.x stable**. Do not use `tauri = "3.0.0-alpha"`.
- HTTP server binds `127.0.0.1:7433` by default; `bind_all` false by default.
- `POST /hook` must answer `200` with empty body in under 50 ms; processing is queued.
- A hook received less than **5 s** ago beats the poll. Poll runs every **2.5 s** with a **2 s** command timeout.
- An agent is `gone` after **2 consecutive** polls without it, or on `SessionEnd`. Its window closes after **10 s** grace.
- Pack manifest requires exactly these six animations: `working`, `idle`, `needs_input`, `delegating`, `waiting_peer`, `gone`.
- Installer writes `~/.claude/settings.json.buddy-backup` before writing, merges without deleting foreign entries, identifies own entries by URL, uses hook `timeout: 2`.
- Hook events installed: `SessionStart`, `SessionEnd`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `PermissionRequest`, `Notification`, `SubagentStart`, `SubagentStop`.
- Positions are persisted keyed by `host + name`.
- Windows: transparent, no decorations, always on top, skip taskbar, not resizable. macOS needs `macOSPrivateApi: true`.
- Malformed events are dropped and logged; nothing panics on bad input.
- Commit after every task.

## Review Focus

1. **Hook arrives for an unknown session before the poll sees it** → agent must be created with provisional name `session_id[:8]` and hook `cwd`, then renamed by the poll without losing position. Test added to Task 9.
2. **Poll output contains agents without `status` or `state` (unexpected shape)** → parser must keep the agent with `Unknown` fields rather than drop the whole snapshot. Test added to Task 2.
3. **`settings.json` has hooks already in the newer object format mixed with an older array format** → installer must merge without corrupting foreign entries, and uninstall must leave them untouched. Test added to Task 5.
4. **Same session name reappears after restart with a new `session_id`** → position lookup is by `host + name`, so the sprite reopens where it was. Test added to Task 10.
5. **`SubagentStop` arrives without a matching `SubagentStart`** (app started mid-run) → counter must saturate at zero, never underflow or panic. Test added to Task 3.

use serde::{Deserialize, Serialize};
use std::path::PathBuf;
use std::time::Instant;

#[derive(Debug, Clone)]
pub struct AgentEvent {
    pub host: String,
    pub session_id: String,
    pub kind: EventKind,
    pub at: Instant,
}

#[derive(Debug, Clone)]
pub enum EventKind {
    Hook(HookEvent),
    Snapshot(Vec<PolledAgent>),
}

#[derive(Debug, Clone)]
pub struct HookEvent {
    pub event: String,
    pub cwd: Option<PathBuf>,
    pub tool_name: Option<String>,
    pub notification_type: Option<String>,
    pub recipient: Option<String>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum PollStatus { Busy, Waiting, Idle, #[serde(other)] Unknown }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum PollState { Working, Blocked, Done, Failed, Stopped, #[serde(other)] Unknown }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
#[serde(rename_all = "lowercase")]
pub enum PollKind { Interactive, Background, #[default] #[serde(other)] Unknown }

#[derive(Debug, Clone, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct PolledAgent {
    pub session_id: String,
    pub name: Option<String>,
    pub cwd: Option<PathBuf>,
    #[serde(default)]
    pub kind: PollKind,
    pub status: Option<PollStatus>,
    pub waiting_for: Option<String>,
    pub state: Option<PollState>,
}

#[derive(Debug)]
pub enum ParseError { MissingField(&'static str), Json(serde_json::Error) }

impl std::fmt::Display for ParseError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            ParseError::MissingField(n) => write!(f, "missing field {n}"),
            ParseError::Json(e) => write!(f, "json: {e}"),
        }
    }
}
impl std::error::Error for ParseError {}
impl From<serde_json::Error> for ParseError { fn from(e: serde_json::Error) -> Self { ParseError::Json(e) } }

pub fn parse_hook(host: &str, body: &serde_json::Value) -> Result<AgentEvent, ParseError> {
    let session_id = body.get("session_id").and_then(|v| v.as_str())
        .ok_or(ParseError::MissingField("session_id"))?.to_string();
    let event = body.get("hook_event_name").and_then(|v| v.as_str())
        .ok_or(ParseError::MissingField("hook_event_name"))?.to_string();
    let str_field = |k: &str| body.get(k).and_then(|v| v.as_str()).map(str::to_string);
    let tool_name = str_field("tool_name");
    let recipient = if tool_name.as_deref() == Some("SendMessage") {
        body.pointer("/tool_input/to").and_then(|v| v.as_str()).map(str::to_string)
    } else { None };
    Ok(AgentEvent {
        host: host.to_string(),
        session_id,
        kind: EventKind::Hook(HookEvent {
            event,
            cwd: str_field("cwd").map(PathBuf::from),
            tool_name,
            notification_type: str_field("notification_type"),
            recipient,
        }),
        at: Instant::now(),
    })
}

pub fn parse_snapshot(host: &str, body: &str) -> Result<AgentEvent, ParseError> {
    let raw: Vec<serde_json::Value> = serde_json::from_str(body)?;
    let agents = raw.into_iter()
        .filter_map(|v| serde_json::from_value::<PolledAgent>(v).ok())
        .collect();
    Ok(AgentEvent { host: host.to_string(), session_id: String::new(),
        kind: EventKind::Snapshot(agents), at: Instant::now() })
}
```

use super::{AgentState, Visible};
use crate::collector::event::{HookEvent, PollKind, PollState, PollStatus, PolledAgent};
use std::time::{Duration, Instant};

pub const HOOK_WINS_FOR: Duration = Duration::from_secs(5);
pub const GONE_AFTER_MISSED: u8 = 2;

const NEEDS_INPUT_NOTIFICATIONS: &[&str] = &["permission_prompt", "elicitation_dialog", "idle_prompt"];

fn effective(s: &AgentState, base: Visible) -> Visible {
    if base == Visible::Gone { return Visible::Gone; }
    if s.subagents > 0 && matches!(base, Visible::Working | Visible::Idle) { return Visible::Delegating; }
    base
}

pub fn apply_hook(s: &mut AgentState, h: &HookEvent, now: Instant) {
    s.last_hook_at = Some(now);
    s.last_seen = now;
    s.missed_polls = 0;
    if s.cwd.is_none() { s.cwd = h.cwd.clone(); }

    let base = match h.event.as_str() {
        "UserPromptSubmit" => {
            s.sent_message = false; s.peer = None; s.waiting_for = None;
            Visible::Working
        }
        "PreToolUse" => Visible::Working,
        "PostToolUse" => {
            if h.tool_name.as_deref() == Some("SendMessage") {
                s.sent_message = true;
                s.peer = h.recipient.clone();
            }
            s.waiting_for = None;
            Visible::Working
        }
        "Stop" => if s.sent_message { Visible::WaitingPeer } else { Visible::Idle },
        "PermissionRequest" => Visible::NeedsInput,
        "Notification" => {
            if h.notification_type.as_deref().is_some_and(|t| NEEDS_INPUT_NOTIFICATIONS.contains(&t)) {
                Visible::NeedsInput
            } else { s.visible }
        }
        "SubagentStart" => { s.subagents += 1; s.visible }
        "SubagentStop" => { s.subagents = s.subagents.saturating_sub(1);
            if s.visible == Visible::Delegating { Visible::Working } else { s.visible } }
        "SessionEnd" => Visible::Gone,
        _ => s.visible,
    };
    s.set_visible(effective(s, base), now);
}

pub fn apply_poll(s: &mut AgentState, p: &PolledAgent, now: Instant) {
    s.last_seen = now;
    s.missed_polls = 0;
    if let Some(n) = &p.name { s.name = n.clone(); }
    if p.cwd.is_some() { s.cwd = p.cwd.clone(); }

    let recent_hook = s.last_hook_at.is_some_and(|t| now.duration_since(t) < HOOK_WINS_FOR);

    // Real "waiting" from the poll always wins over inferred states.
    if p.status == Some(PollStatus::Waiting) {
        s.waiting_for = p.waiting_for.clone();
        s.set_visible(Visible::NeedsInput, now);
        return;
    }
    if recent_hook && s.visible != Visible::Gone { return; }

    let base = match (p.kind, p.status, p.state) {
        (PollKind::Background, _, Some(st)) => match st {
            PollState::Working => Visible::Working,
            PollState::Blocked => Visible::NeedsInput,
            PollState::Done | PollState::Failed | PollState::Stopped => Visible::Gone,
            PollState::Unknown => s.visible,
        },
        (_, Some(PollStatus::Busy), _) => { s.sent_message = false; s.peer = None; s.waiting_for = None; Visible::Working }
        (_, Some(PollStatus::Idle), _) => if s.sent_message { Visible::WaitingPeer } else { Visible::Idle },
        _ => s.visible,
    };
    s.set_visible(effective(s, base), now);
}

pub fn mark_missed(s: &mut AgentState, now: Instant) {
    s.missed_polls = s.missed_polls.saturating_add(1);
    if s.missed_polls >= GONE_AFTER_MISSED { s.set_visible(Visible::Gone, now); }
}

use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

pub const REQUIRED: [&str; 6] = ["working", "idle", "needs_input", "delegating", "waiting_peer", "gone"];

fn default_true() -> bool { true }
fn default_scale() -> u32 { 1 }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Animation {
    pub sheet: String,
    pub row: u32,
    pub frames: u32,
    pub fps: u32,
    #[serde(default = "default_true")]
    pub r#loop: bool,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Manifest {
    pub name: String,
    pub frame_size: [u32; 2],
    #[serde(default = "default_scale")]
    pub scale: u32,
    pub animations: BTreeMap<String, Animation>,
}

#[derive(Debug)]
pub enum PackError {
    Io(std::io::Error),
    Json(serde_json::Error),
    MissingAnimation(String),
    SheetNotFound(PathBuf),
    BadPng(PathBuf),
    BadDimensions { sheet: String, width: u32, height: u32, frame: [u32; 2] },
    RowOutOfRange { animation: String, row: u32, rows: u32 },
    FramesOutOfRange { animation: String, frames: u32, cols: u32 },
}
impl std::fmt::Display for PackError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { write!(f, "{self:?}") }
}
impl std::error::Error for PackError {}
impl From<std::io::Error> for PackError { fn from(e: std::io::Error) -> Self { PackError::Io(e) } }
impl From<serde_json::Error> for PackError { fn from(e: serde_json::Error) -> Self { PackError::Json(e) } }

fn png_size(path: &Path) -> Result<(u32, u32), PackError> {
    let f = std::fs::File::open(path)?;
    let dec = png::Decoder::new(std::io::BufReader::new(f));
    let reader = dec.read_info().map_err(|_| PackError::BadPng(path.to_path_buf()))?;
    let info = reader.info();
    Ok((info.width, info.height))
}

pub fn load_pack(dir: &Path) -> Result<Manifest, PackError> {
    let text = std::fs::read_to_string(dir.join("pack.json"))?;
    let m: Manifest = serde_json::from_str(&text)?;
    for req in REQUIRED {
        if !m.animations.contains_key(req) { return Err(PackError::MissingAnimation(req.to_string())); }
    }
    let [fw, fh] = m.frame_size;
    for (name, a) in &m.animations {
        let sheet_path = dir.join(&a.sheet);
        if !sheet_path.is_file() { return Err(PackError::SheetNotFound(sheet_path)); }
        let (w, h) = png_size(&sheet_path)?;
        if fw == 0 || fh == 0 || w % fw != 0 || h % fh != 0 {
            return Err(PackError::BadDimensions { sheet: a.sheet.clone(), width: w, height: h, frame: m.frame_size });
        }
        let rows = h / fh; let cols = w / fw;
        if a.row >= rows { return Err(PackError::RowOutOfRange { animation: name.clone(), row: a.row, rows }); }
        if a.frames == 0 || a.frames > cols {
            return Err(PackError::FramesOutOfRange { animation: name.clone(), frames: a.frames, cols });
        }
    }
    Ok(m)
}

pub fn list_packs(root: &Path) -> Vec<String> {
    let Ok(rd) = std::fs::read_dir(root) else { return vec![] };
    let mut v: Vec<String> = rd.filter_map(|e| e.ok())
        .filter(|e| e.path().join("pack.json").is_file())
        .filter_map(|e| e.file_name().into_string().ok())
        .collect();
    v.sort();
    v
}

```js
import { PNG } from "pngjs";
import { writeFileSync, mkdirSync } from "node:fs";

const F = 64, COLS = 6, ROWS = 6;
const png = new PNG({ width: F * COLS, height: F * ROWS });
const px = (x, y, [r, g, b, a = 255]) => {
  if (x < 0 || y < 0 || x >= png.width || y >= png.height) return;
  const i = (png.width * y + x) << 2;
  png.data[i] = r; png.data[i + 1] = g; png.data[i + 2] = b; png.data[i + 3] = a;
};
const rect = (x, y, w, h, c) => { for (let j = 0; j < h; j++) for (let i = 0; i < w; i++) px(x + i, y + j, c); };
const circle = (cx, cy, r, c) => { for (let y = -r; y <= r; y++) for (let x = -r; x <= r; x++) if (x * x + y * y <= r * r) px(cx + x, cy + y, c); };

const BODY = { working: [90, 170, 255], idle: [150, 150, 170], needs_input: [255, 170, 60],
               delegating: [140, 220, 140], waiting_peer: [200, 150, 255], gone: [120, 120, 120] };
const BLACK = [20, 20, 30], WHITE = [250, 250, 250], RED = [230, 60, 60];
const order = ["working", "idle", "needs_input", "delegating", "waiting_peer", "gone"];

function body(ox, oy, color, squash = 0, alpha = 255) {
  const c = [...color, alpha];
  circle(ox + 32, oy + 40 + squash, 18 - squash, c);
  rect(ox + 18, oy + 44, 28, 10 - squash, c);
}
function eyes(ox, oy, open = true, dx = 0) {
  if (open) { circle(ox + 25 + dx, oy + 36, 3, WHITE); circle(ox + 39 + dx, oy + 36, 3, WHITE);
              circle(ox + 25 + dx, oy + 36, 1, BLACK); circle(ox + 39 + dx, oy + 36, 1, BLACK); }
  else { rect(ox + 22, oy + 36, 7, 2, BLACK); rect(ox + 36, oy + 36, 7, 2, BLACK); }
}

order.forEach((state, row) => {
  for (let col = 0; col < COLS; col++) {
    const ox = col * F, oy = row * F;
    switch (state) {
      case "working": { body(ox, oy, BODY[state], col % 2); eyes(ox, oy, true);
        rect(ox + 14 + (col % 3) * 2, oy + 50, 8, 4, BLACK); rect(ox + 42 - (col % 3) * 2, oy + 50, 8, 4, BLACK); break; }
      case "idle": { body(ox, oy, BODY[state], col < 2 ? 0 : 1); eyes(ox, oy, false);
        if (col % 2) rect(ox + 46, oy + 18 - col * 2, 4, 4, BLACK); break; }
      case "needs_input": { body(ox, oy, BODY[state]); eyes(ox, oy, true);
        if (col % 2 === 0) { rect(ox + 30, oy + 6, 4, 12, RED); rect(ox + 30, oy + 20, 4, 4, RED); } break; }

use serde_json::{json, Value};
use std::path::{Path, PathBuf};

pub const HOOK_EVENTS: [&str; 10] = ["SessionStart", "SessionEnd", "UserPromptSubmit", "PreToolUse",
    "PostToolUse", "Stop", "PermissionRequest", "Notification", "SubagentStart", "SubagentStop"];

#[derive(Debug)]
pub enum InstallError { Io(std::io::Error), Json(serde_json::Error) }
impl std::fmt::Display for InstallError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result { write!(f, "{self:?}") }
}
impl std::error::Error for InstallError {}
impl From<std::io::Error> for InstallError { fn from(e: std::io::Error) -> Self { InstallError::Io(e) } }
impl From<serde_json::Error> for InstallError { fn from(e: serde_json::Error) -> Self { InstallError::Json(e) } }

pub fn hook_entry(url: &str, token: &str) -> Value {
    json!({ "hooks": [{ "type": "http", "url": url,
        "headers": { "Authorization": format!("Bearer {token}") }, "timeout": 2 }] })
}

fn group_has_url(group: &Value, url: &str) -> bool {
    group.get("hooks").and_then(|h| h.as_array())
        .is_some_and(|arr| arr.iter().any(|h| h.get("url").and_then(|u| u.as_str()) == Some(url)))
}

pub fn remove_hooks(settings: &mut Value, url: &str) {
    let Some(hooks) = settings.get_mut("hooks").and_then(|h| h.as_object_mut()) else { return };
    let mut empty = vec![];
    for (ev, groups) in hooks.iter_mut() {
        if let Some(arr) = groups.as_array_mut() {
            arr.retain(|g| !group_has_url(g, url));
            if arr.is_empty() { empty.push(ev.clone()); }
        }
    }
    for ev in empty { hooks.remove(&ev); }
}

pub fn merge_hooks(settings: &mut Value, url: &str, token: &str) {
    remove_hooks(settings, url);
    if !settings.is_object() { *settings = json!({}); }
    let obj = settings.as_object_mut().unwrap();
    let hooks = obj.entry("hooks").or_insert_with(|| json!({}));
    if !hooks.is_object() { *hooks = json!({}); }
    let hooks = hooks.as_object_mut().unwrap();
    for ev in HOOK_EVENTS {
        let groups = hooks.entry(ev).or_insert_with(|| json!([]));
        if !groups.is_array() { *groups = json!([]); }
        groups.as_array_mut().unwrap().push(hook_entry(url, token));
    }
}

pub fn is_installed(settings: &Value, url: &str) -> bool {
    settings.get("hooks").and_then(|h| h.as_object())
        .is_some_and(|m| m.values().any(|groups|
            groups.as_array().is_some_and(|arr| arr.iter().any(|g| group_has_url(g, url)))))
}

fn read_settings(path: &Path) -> Result<Value, InstallError> {
    if !path.exists() { return Ok(json!({})); }
    let text = std::fs::read_to_string(path)?;
    if text.trim().is_empty() { return Ok(json!({})); }
    Ok(serde_json::from_str(&text)?)
}

fn write_with_backup(path: &Path, value: &Value) -> Result<(), InstallError> {
    if path.exists() {
        let backup = path.with_file_name(format!("{}.buddy-backup",
            path.file_name().unwrap().to_string_lossy()));
        std::fs::copy(path, backup)?;
    } else if let Some(parent) = path.parent() { std::fs::create_dir_all(parent)?; }
    std::fs::write(path, serde_json::to_string_pretty(value)?)?;
    Ok(())
}

pub fn install(path: &Path, url: &str, token: &str) -> Result<(), InstallError> {
    let mut v = read_settings(path)?;
    merge_hooks(&mut v, url, token);
    write_with_backup(path, &v)
}

pub fn uninstall(path: &Path, url: &str) -> Result<(), InstallError> {
    let mut v = read_settings(path)?;
    remove_hooks(&mut v, url);
    write_with_backup(path, &v)
}

pub fn default_settings_path() -> PathBuf {
    let base = std::env::var_os("CLAUDE_CONFIG_DIR").map(PathBuf::from)
        .or_else(|| directories::BaseDirs::new().map(|b| b.home_dir().join(".claude")))
        .unwrap_or_else(|| PathBuf::from(".claude"));
    base.join("settings.json")
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Config {
    pub port: u16,
    pub token: String,
    pub pack: String,
    pub bind_all: bool,
}

    fn default() -> Self {
        Self { port: 7433, token: generate_token(), pack: "default".into(), bind_all: false }
    }

impl Config {
    pub fn load(path: &Path) -> Config {
        std::fs::read_to_string(path).ok()
            .and_then(|t| serde_json::from_str::<Config>(&t).ok())
            .filter(|c| c.token.len() == 32)
            .unwrap_or_default()

    pub fn save(&self, path: &Path) -> std::io::Result<()> {
        if let Some(p) = path.parent() { std::fs::create_dir_all(p)?; }
        std::fs::write(path, serde_json::to_string_pretty(self).unwrap())
    }
    pub fn hook_url(&self) -> String { format!("http://127.0.0.1:{}/hook", self.port) }

        let ip = if self.bind_all { Ipv4Addr::UNSPECIFIED } else { Ipv4Addr::LOCALHOST };
        SocketAddr::new(IpAddr::V4(ip), self.port)
    }
}

    rand::rng().fill_bytes(&mut b);
    b.iter().map(|x| format!("{x:02x}")).collect()

```rust
use super::event::{parse_snapshot, AgentEvent, ParseError};
use std::time::Duration;
use tokio::sync::{mpsc, watch};

pub const POLL_INTERVAL: Duration = Duration::from_millis(2500);
pub const POLL_TIMEOUT: Duration = Duration::from_secs(2);

#[derive(Debug)]
pub enum PollError { Spawn(std::io::Error), Timeout, NonZero(i32), Parse(ParseError) }
impl std::fmt::Display for PollError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            PollError::Spawn(e) => write!(f, "cannot run claude: {e}"),
            PollError::Timeout => write!(f, "claude agents timed out"),
            PollError::NonZero(c) => write!(f, "claude agents exited with {c}"),
            PollError::Parse(e) => write!(f, "cannot parse claude agents output: {e}"),
        }
    }
}

pub fn claude_bin() -> String {
    std::env::var("BUDDY_CLAUDE_BIN").unwrap_or_else(|_| "claude".into())
}

pub async fn poll_once(host: &str, bin: &str) -> Result<AgentEvent, PollError> {
    let mut cmd = tokio::process::Command::new(bin);
    cmd.args(["agents", "--json", "--all"]).kill_on_drop(true)
        .stdout(std::process::Stdio::piped()).stderr(std::process::Stdio::null());
    let child = cmd.spawn().map_err(PollError::Spawn)?;
    let out = tokio::time::timeout(POLL_TIMEOUT, child.wait_with_output()).await
        .map_err(|_| PollError::Timeout)?.map_err(PollError::Spawn)?;
    if !out.status.success() { return Err(PollError::NonZero(out.status.code().unwrap_or(-1))); }
    parse_snapshot(host, &String::from_utf8_lossy(&out.stdout)).map_err(PollError::Parse)
}

pub fn spawn_poller(host: String, tx: mpsc::Sender<AgentEvent>, errors: watch::Sender<Option<String>>)
    -> tokio::task::JoinHandle<()> {
    tokio::spawn(async move {
        let bin = claude_bin();
        let mut tick = tokio::time::interval(POLL_INTERVAL);
        let mut last_err: Option<String> = None;
        loop {
            tick.tick().await;
            match poll_once(&host, &bin).await {
                Ok(ev) => {
                    if last_err.take().is_some() { let _ = errors.send(None); }
                    if tx.send(ev).await.is_err() { break; }
                }
                Err(e) => {
                    let msg = e.to_string();
                    if last_err.as_deref() != Some(&msg) {
                        log::warn!("poller: {msg}");
                        let _ = errors.send(Some(msg.clone()));
                        last_err = Some(msg);
                    }
                }
            }
        }
    })
}

async fn hook(State(st): State<AppState>, headers: HeaderMap, body: Bytes) -> StatusCode {
    let expected = format!("Bearer {}", st.token);
    let ok = headers.get("authorization").and_then(|v| v.to_str().ok()) == Some(expected.as_str());
    if !ok { return StatusCode::UNAUTHORIZED; }
    match serde_json::from_slice::<serde_json::Value>(&body) {
        Ok(v) => match parse_hook(&st.host, &v) {
            Ok(ev) => { let _ = st.tx.try_send(ev); }
            Err(e) => log::warn!("hook dropped: {e}"),
        },
        Err(e) => log::warn!("hook body not json: {e}"),
    }
    StatusCode::OK
}

    tokio::spawn(async move {
        if let Err(e) = axum::serve(listener, app).await { log::error!("hooks server: {e}"); }

```rust
use super::machine::{apply_hook, apply_poll, mark_missed};
use super::{AgentId, AgentState, Visible};
use crate::collector::event::{AgentEvent, EventKind};
use serde::Serialize;
use std::collections::{HashMap, HashSet};
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Serialize, PartialEq)]
pub struct AgentView {
    pub key: String,
    pub host: String,
    pub session_id: String,
    pub name: String,
    pub cwd: Option<String>,
    pub visible: Visible,
    pub waiting_for: Option<String>,
    pub peer: Option<String>,
    pub since_secs: u64,
}

#[derive(Debug, Clone)]
pub enum Change { Added(AgentView), Updated(AgentView), Removed(String) }

#[derive(Debug, Clone, PartialEq)]
struct Fingerprint(Visible, String, Option<String>, Option<String>);
fn fp(s: &AgentState) -> Fingerprint { Fingerprint(s.visible, s.name.clone(), s.waiting_for.clone(), s.peer.clone()) }

pub struct Store {
    agents: HashMap<String, AgentState>,
    pub gone_grace: Duration,
}

impl Default for Store { fn default() -> Self { Self::new() } }

impl Store {
    pub fn new() -> Self { Self { agents: HashMap::new(), gone_grace: Duration::from_secs(10) } }

    pub fn view(&self, s: &AgentState, now: Instant) -> AgentView {
        AgentView {
            key: s.id.key(), host: s.id.host.clone(), session_id: s.id.session_id.clone(),
            name: s.name.clone(), cwd: s.cwd.as_ref().map(|p| p.to_string_lossy().into_owned()),
            visible: s.visible, waiting_for: s.waiting_for.clone(), peer: s.peer.clone(),
            since_secs: now.saturating_duration_since(s.since).as_secs(),
        }
    }

    pub fn views(&self, now: Instant) -> Vec<AgentView> {
        let mut v: Vec<_> = self.agents.values().map(|s| self.view(s, now)).collect();
        v.sort_by(|a, b| a.name.cmp(&b.name));
        v
    }

    fn upsert<F: FnOnce(&mut AgentState)>(&mut self, id: AgentId, now: Instant, f: F) -> Option<Change> {
        let key = id.key();
        let is_new = !self.agents.contains_key(&key);
        let s = self.agents.entry(key).or_insert_with(|| AgentState::new(id, now));
        let before = fp(s);
        f(s);
        let view = self.view(s, now);
        if is_new { Some(Change::Added(view)) }
        else if fp(s) != before { Some(Change::Updated(view)) }
        else { None }
    }

    pub fn apply(&mut self, ev: &AgentEvent) -> Vec<Change> {
        let now = ev.at;
        match &ev.kind {
            EventKind::Hook(h) => {
                if ev.session_id.is_empty() { return vec![]; }
                let id = AgentId { host: ev.host.clone(), session_id: ev.session_id.clone() };
                self.upsert(id, now, |s| apply_hook(s, h, now)).into_iter().collect()
            }
            EventKind::Snapshot(list) => {
                let mut changes = vec![];
                let mut seen = HashSet::new();
                for p in list {
                    if p.session_id.is_empty() { continue; }
                    let id = AgentId { host: ev.host.clone(), session_id: p.session_id.clone() };
                    seen.insert(id.key());
                    changes.extend(self.upsert(id, now, |s| apply_poll(s, p, now)));
                }
                for (key, s) in self.agents.iter_mut() {
                    if s.id.host != ev.host || seen.contains(key) || s.visible == Visible::Gone { continue; }
                    let before = fp(s);
                    mark_missed(s, now);
                    if fp(s) != before {
                        let view = AgentView { key: key.clone(), host: s.id.host.clone(), session_id: s.id.session_id.clone(),
                            name: s.name.clone(), cwd: s.cwd.as_ref().map(|p| p.to_string_lossy().into_owned()),
                            visible: s.visible, waiting_for: s.waiting_for.clone(), peer: s.peer.clone(), since_secs: 0 };
                        changes.push(Change::Updated(view));
                    }
                }
                changes
            }
        }
    }

    pub fn sweep(&mut self, now: Instant) -> Vec<Change> {
        let grace = self.gone_grace;
        let dead: Vec<String> = self.agents.iter()
            .filter(|(_, s)| s.visible == Visible::Gone && now.saturating_duration_since(s.since) >= grace)
            .map(|(k, _)| k.clone()).collect();
        for k in &dead { self.agents.remove(k); }
        dead.into_iter().map(Change::Removed).collect()
    }
}

use std::collections::BTreeMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub struct Pos { pub x: i32, pub y: i32 }

pub struct Positions { map: BTreeMap<String, Pos>, path: PathBuf }

fn key(host: &str, name: &str) -> String { format!("{host}:{name}") }

impl Positions {
    pub fn load(path: PathBuf) -> Self {
        let map = std::fs::read_to_string(&path).ok()
            .and_then(|t| serde_json::from_str(&t).ok()).unwrap_or_default();
        Self { map, path }
    }
    pub fn get(&self, host: &str, name: &str) -> Option<Pos> { self.map.get(&key(host, name)).copied() }
    pub fn set(&mut self, host: &str, name: &str, p: Pos) {
        self.map.insert(key(host, name), p);
        if let Some(parent) = self.path.parent() { let _ = std::fs::create_dir_all(parent); }
        if let Err(e) = std::fs::write(&self.path, serde_json::to_string_pretty(&self.map).unwrap()) {
            log::warn!("cannot save positions: {e}");
        }
    }
    pub fn cascade(&self, index: usize, screen_w: i32, screen_h: i32, win_w: i32, win_h: i32) -> Pos {
        const MARGIN: i32 = 24; const DX: i32 = 40; const DY: i32 = 30;
        let start_x = screen_w - win_w - MARGIN;
        let start_y = screen_h - win_h - MARGIN;
        let per_row = ((start_x / DX).max(1)) as usize;
        let col = (index % per_row) as i32;
        let row = (index / per_row) as i32;
        let x = (start_x - col * DX).max(0);
        let y = (start_y - col * DY - row * (win_h + MARGIN)).rem_euclid(start_y.max(1));
        Pos { x, y }
    }
}

use crate::state::store::{AgentView, Change};
use crate::windows::positions::{Pos, Positions};
use tauri::{AppHandle, Emitter, Manager, WebviewUrl, WebviewWindowBuilder};

pub fn label_for(key: &str) -> String { format!("sprite-{}", key.replace([':', '/', '.'], "_")) }

fn window_size(m: &Manifest) -> (f64, f64) {
    let [w, h] = m.frame_size;
    ((w * m.scale) as f64, (h * m.scale) as f64 + 56.0) // 56px for tooltip below the sprite
}

pub fn apply_changes(app: &AppHandle, changes: &[Change], manifest: &Manifest, positions: &mut Positions) {
    for ch in changes {
        match ch {
            Change::Added(v) => { ensure_window(app, v, manifest, positions); push_state(app, v); }
            Change::Updated(v) => { ensure_window(app, v, manifest, positions); push_state(app, v); }
            Change::Removed(key) => {
                if let Some(w) = app.get_webview_window(&label_for(key)) { let _ = w.close(); }
            }
        }
    }
}

fn push_state(app: &AppHandle, v: &AgentView) {
    if let Some(w) = app.get_webview_window(&label_for(&v.key)) { let _ = w.emit("agent-state", v); }
}

fn ensure_window(app: &AppHandle, v: &AgentView, manifest: &Manifest, positions: &mut Positions) {
    let label = label_for(&v.key);
    if app.get_webview_window(&label).is_some() { return; }
    let (w, h) = window_size(manifest);
    let pos = positions.get(&v.host, &v.name).unwrap_or_else(|| {
        let (sw, sh) = app.primary_monitor().ok().flatten()
            .map(|m| { let s = m.size(); let f = m.scale_factor(); ((s.width as f64 / f) as i32, (s.height as f64 / f) as i32) })
            .unwrap_or((1440, 900));
        let index = app.webview_windows().keys().filter(|k| k.starts_with("sprite-")).count();
        positions.cascade(index, sw, sh, w as i32, h as i32)
    });
    let url = WebviewUrl::App(format!("sprite/index.html?key={}", urlencoding(&v.key)).into());
    let built = WebviewWindowBuilder::new(app, &label, url)
        .title(&v.name).inner_size(w, h).position(pos.x as f64, pos.y as f64)
        .transparent(true).decorations(false).always_on_top(true).skip_taskbar(true)
        .resizable(false).shadow(false).visible_on_all_workspaces(true)
        .build();
    if let Err(e) = built { log::error!("cannot create sprite window: {e}"); }
}

    let path = app.packs_root.join(&pack).join(&sheet);
    let bytes = std::fs::read(&path).map_err(|e| e.to_string())?;
    use std::fmt::Write;
    let mut b64 = String::new();
    base64_encode(&bytes, &mut b64);
    let mut s = String::from("data:image/png;base64,"); let _ = write!(s, "{b64}");
    Ok(s)
}

fn base64_encode(input: &[u8], out: &mut String) {
    const T: &[u8; 64] = b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
    for chunk in input.chunks(3) {
        let b = [chunk[0], *chunk.get(1).unwrap_or(&0), *chunk.get(2).unwrap_or(&0)];
        let n = (b[0] as u32) << 16 | (b[1] as u32) << 8 | b[2] as u32;
        out.push(T[(n >> 18) as usize & 63] as char);
        out.push(T[(n >> 12) as usize & 63] as char);
        out.push(if chunk.len() > 1 { T[(n >> 6) as usize & 63] as char } else { '=' });
        out.push(if chunk.len() > 2 { T[n as usize & 63] as char } else { '=' });
    }
}

```ts
import type { Animation, Manifest } from "../shared/types";

export class Animator {
  private anim: Animation;
  private frame = 0;
  private acc = 0;
  private finished = false;

  constructor(private manifest: Manifest, name: string) {
    this.anim = manifest.animations[name] ?? manifest.animations.idle;
  }

  play(name: string) {
    const next = this.manifest.animations[name] ?? this.manifest.animations.idle;
    if (next === this.anim) return;
    this.anim = next; this.frame = 0; this.acc = 0; this.finished = false;
  }

  /** advance by dt ms; returns {sx, sy} source rect origin in the sheet */
  tick(dt: number): { sheet: string; sx: number; sy: number } {
    if (!this.finished) {
      this.acc += dt;
      const step = 1000 / Math.max(1, this.anim.fps);
      while (this.acc >= step) {
        this.acc -= step;
        if (this.frame + 1 >= this.anim.frames) {
          if (this.anim.loop) this.frame = 0; else { this.finished = true; break; }
        } else this.frame++;
      }
    }
    const [fw, fh] = this.manifest.frameSize;
    return { sheet: this.anim.sheet, sx: this.frame * fw, sy: this.anim.row * fh };
  }
}

    <ul>${agents.map((a) => `<li><b>${a.name}</b> · ${a.visible}${a.waiting_for ? ` (${a.waiting_for})` : ""}${a.peer ? ` → ${a.peer}` : ""}<br><code>${a.cwd ?? ""}</code></li>`).join("") || "<li>none</li>"}</ul>`;
  document.getElementById("hooks")!.onclick = async () => {
    try { await invoke(status.hooks_installed ? "uninstall_hooks" : "install_hooks"); }
    catch (e) { alert(`Error: ${e}`); }
    await refresh();
  };
  (document.getElementById("pack") as HTMLSelectElement).onchange = async (e) => {
    try { await invoke("set_pack", { name: (e.target as HTMLSelectElement).value }); } catch (err) { alert(`Invalid pack: ${err}`); }
    await refresh();
  };
  (document.getElementById("auto") as HTMLInputElement).onchange = async (e) => {
    (e.target as HTMLInputElement).checked ? await enable() : await disable();
    autostart = await isEnabled();
  };
}

async function refresh() {
  [status, agents, packs, autostart] = await Promise.all([
    invoke<Status>("get_status"), invoke<AgentView[]>("list_agents"), invoke<string[]>("list_pack_names"), isEnabled().catch(() => false),
  ]);
  render();
}

listen<AgentView[]>("agents", (e) => { agents = e.payload; render(); });
refresh();
setInterval(() => invoke<Status>("get_status").then((s) => { if (JSON.stringify(s) !== JSON.stringify(status)) { status = s; render(); } }), 3000);

# CodePets

A desktop pet for Claude Code: one floating sprite per session, animated according to its state
(working, idle, needs input, delegating, waiting for another agent, finished).

## Requirements
- Rust 1.93+, Node 20+, Claude Code 2.1.224+ (`claude agents --json`).

## Development
```bash
npm install
npm run gen:pack        # regenerates assets/packs/default
cargo tauri dev
```
Visual check without Claude Code: run `npm run dev` and open
`http://localhost:1420/sprite/index.html?mock=working` (or idle, needs_input, delegating, waiting_peer, gone).

## Usage
1. Open CodePets (tray icon) → Settings → **Connect to Claude Code**.
   This adds `http` hooks to `~/.claude/settings.json` (the previous file is backed up as `settings.json.buddy-backup`).
2. Each Claude Code session appears as a sprite. Drag it wherever you like; its position is remembered.
3. Click a sprite to see its name, folder and state.

## Sprite packs
`assets/packs/<name>/pack.json` + PNGs. Six required animations: `working`, `idle`,
`needs_input`, `delegating`, `waiting_peer`, `gone`. See `assets/packs/default/pack.json`.

## How it works
- Claude Code HTTP hooks → `POST 127.0.0.1:7433/hook` (immediate push).
- Poll of `claude agents --json --all` every 2.5 s (reconciliation).
- Spec: `doc/specs/2026-10-07-codepets-design.md`.
```
